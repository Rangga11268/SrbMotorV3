Versi 1: Spesifikasi Node Fisik (Physical Nodes)

Deskripsi: Menggambarkan rancangan fisik paling mendasar. Aktor Customer menggunakan perangkat pribadinya (Customer Device) untuk mengakses Office Server yang berada di kantor utama SRB Motor melalui jalur komunikasi internet umum menggunakan protokol HTTP/HTTPS.

Versi 2: Konfigurasi dengan Komponen/Artifacts

Deskripsi: Mendetailkan komponen perangkat lunak (Artifacts) yang dideploy di dalam masing-masing node fisik. Menunjukkan lapisan antarmuka pengguna (HCI Layer) pada sisi klien, serta logika pemrosesan data (PD Layer) dan pengelolaan data (DM Layer) pada sisi server menggunakan nama sistem riil (SRB Motor System).

Versi 4: Top-Level Network Model (Jaringan Internal Gedung SRB Motor)

Menggambarkan topologi jaringan tingkat tinggi (Top-Level Network Model) sesuai standar UML akademik. Node pusat didefinisikan sebagai «network» yang menghubungkan seluruh «subnetwork» divisi kerja melalui jalur komunikasi (communication paths) dengan stereotip «intranet».
