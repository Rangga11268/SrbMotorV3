Panduan Presentasi Deployment Diagram

Sistem Informasi Penjualan & Booking Service SRB Motor

Pengantar Presentasi

"Selamat pagi/siang. Kami mempresentasikan rancangan arsitektur fisik dan model distribusi sistem SRB Motor dalam 4 versi evolusi. Rancangan ini bertujuan menunjukkan kesiapan dan skalabilitas infrastruktur dari skala lokal sederhana hingga segmentasi jaringan divisi internal yang aman."

Versi 1: Spesifikasi Node Fisik (Physical Nodes)

Fokus: Pemetaan perangkat keras dasar.
"Menghubungkan secara fisik perangkat pengguna (Customer Device) dengan Office Server di kantor utama SRB Motor. Hubungan fisik ini berjalan secara langsung melewati internet menggunakan protokol komunikasi standar HTTP/HTTPS."

Versi 2: Konfigurasi dengan Komponen/Artifacts

Fokus: Pembagian software layer di dalam node menggunakan nama sistem riil.
"Masuk ke Versi 2, kami mendetailkan komponen perangkat lunak (Artifacts) yang berjalan. Di sisi klien (Front Office PC), berjalan antarmuka pengguna «HCI Layer» SRB Motor System. Sedangkan di sisi Office Server, dideploy komponen logika program «PD Layer» SRB Motor System dan basis data «DM Layer» SRB Motor System."

Versi 3: Distribusi Terpisah (Separated Server & Database)

Fokus: Pemisahan database fisik dari server utama.
"Pada Versi 3, arsitektur dikembangkan dengan memisahkan basis data secara fisik. Perangkat kasir/admin (Front Office PC) terhubung melalui jaringan «LAN» ke Office Server utama, dan server utama tersebut terhubung langsung ke tempat penyimpanan data terpisah (Data Base)."

Versi 4: Top-Level Network Model (Jaringan Internal Gedung)

Fokus: Segmentasi jaringan lokal (LAN) internal.
"Menggambarkan segmentasi jaringan internal gedung operasional SRB Motor secara logis sesuai modul kuliah. Node pusat bertipe «network» LAN membagikan koneksi komunikasi «intranet» ke empat divisi kerja utama bertipe «subnetwork» (*Server Room*, *Front Office*, *Workshop*, dan *Showroom*)."
