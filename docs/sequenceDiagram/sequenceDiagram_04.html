Pembelian Tunai Motor

Skenario Customer memesan motor secara tunai melalui serangkaian antarmuka (Katalog, Form, Halaman Pembayaran) dan Webhook Midtrans.

sequenceDiagram
    autonumber
    actor C as Customer
    participant HK as <<boundary>>
HalamanKatalog
    participant PC as <<control>>
PemesananController
    participant M as <<entity>>
Motor
    participant FP as <<boundary>>
FormPemesanan
    participant Pj as <<entity>>
Penjualan
    
    %% NEW BOUNDARY FOR PAYMENT
    participant HP as <<boundary>>
HalamanPembayaran
    
    participant PyC as <<control>>
PembayaranController
    participant Py as <<entity>>
Pembayaran
    participant MD as <<system>>
Midtrans
    participant NS as <<control>>
NotifService
    actor A as Admin

    C->>HK: klikBeliTunai(idMotor, warna)
    activate HK
    HK->>PC: cekStok(idMotor)
    activate PC
    PC->>M: getStok(idMotor)
    activate M
    M-->>PC: return jumlahStok
    deactivate M
    
    alt Stok Tidak Tersedia
        PC-->>HK: return status(gagal, "Stok tidak tersedia")
        HK->>HK: tampilkanPesanError("Stok tidak tersedia")
    else Stok Tersedia
        PC-->>HK: return status(tersedia)
        HK->>FP: tampilkanFormPemesanan()
        deactivate HK
        activate FP
        FP->>FP: tampilkanForm()
        
        C->>FP: inputDataPribadiDanUpload(KTP, KK)
        FP->>PC: submitPemesanan(dataCustomer, dokumen)
        
        PC->>Pj: createPenjualanSementara(data)
        activate Pj
        Pj-->>PC: return idPenjualan
        deactivate Pj
        
        PC-->>FP: return status(sukses, idPenjualan)
        deactivate PC
        
        %% TRANSITION TO NEW BOUNDARY (PAYMENT PAGE)
        FP->>HP: redirectKePembayaran(idPenjualan)
        deactivate FP
        activate HP
        
        HP->>PyC: generateTagihanBooking(idPenjualan)
        activate PyC
        PyC-->>HP: return opsiMidtrans
        deactivate PyC
        
        HP->>HP: tampilkanDetailTagihan()
        
        C->>HP: klikBayarSekarang()
        HP->>PyC: dapatkanUrlPembayaran()
        activate PyC
        PyC-->>HP: return urlMidtrans
        deactivate PyC
        
        HP->>MD: redirectKeMidtrans()
        deactivate HP
        
        C->>MD: lakukanPembayaranBookingFee()
        activate MD
        MD->>PyC: prosesWebhook(payloadMidtrans)
        activate PyC
        
        alt Pembayaran Gagal
            PyC->>Py: updateStatusPembayaran(gagal)
            activate Py
            Py-->>PyC: return ok
            deactivate Py
            PyC->>Pj: batalkanPenjualan(idPenjualan)
            activate Pj
            Pj-->>PyC: return ok
            deactivate Pj
            PyC-->>MD: return HTTP 200
            Note over C, PyC: Customer melihat notif gagal di aplikasi/sistem
        else Pembayaran Berhasil
            PyC->>Py: simpanPembayaran(dataBayar, LUNAS)
            activate Py
            Py-->>PyC: return ok
            deactivate Py
            PyC->>Pj: updateStatusPenjualan(BERHASIL)
            activate Pj
            Pj-->>PyC: return ok
            deactivate Pj
            PyC-->>MD: return HTTP 200
            deactivate MD
            
            PyC->>NS: kirimNotifPemesananBaru(idPenjualan)
            deactivate PyC
            activate NS
            
            %% Push Notif adalah pengecualian, ini interaksi aktif sistem WA ke aktor
            NS->>C: kirimNotifWhatsApp("Pemesanan Berhasil")
            NS->>A: pushNotifikasiDashboard("Pesanan Masuk")
            
            Note over A: Admin memproses transaksi (Memicu UC-07)
            
            NS->>NS: jadwalkanNotifSTNK(tanggalSekarang + 7 hari)
            NS->>NS: jadwalkanNotifBPKB(tanggalSekarang + 45 hari)
            deactivate NS
            
            Note over NS, C: Waktu berlalu sesuai jadwal pengingat
            activate NS
            NS->>C: kirimNotifWhatsApp("STNK/BPKB dapat diambil")
            deactivate NS
        end
    end
