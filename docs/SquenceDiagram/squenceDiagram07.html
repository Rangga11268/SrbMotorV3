Pengelolaan Transaksi Motor

USE CASE SKENARIO — Transaksi Motor

Use Case ID UC-07
Nama Use Case Mengelola Transaksi Motor
Aktor Admin, Customer, Sistem
Deskripsi Admin memverifikasi dokumen transaksi pelanggan, memperbarui status pengerjaan motor (Konfirmasi, Proses, Selesai), serta mengirimkan notifikasi pengambilan STNK & BPKB secara otomatis atau manual.
Precondition Admin sudah login dan terdapat data transaksi yang masuk dari UC-04 (Pesan Motor Tunai) atau UC-05 (Ajukan Kredit Motor).
Postcondition Status transaksi berhasil diperbarui. Jika status = Selesai, sistem secara otomatis menjadwalkan pengiriman notifikasi STNK & BPKB kepada Customer.
Skenario Utama 1. Admin membuka menu 'Transaksi Motor' → 2. Sistem menampilkan daftar seluruh transaksi → 3. Admin memilih transaksi → 4. Admin memverifikasi data dan dokumen → 5. Admin memperbarui status transaksi (Konfirmasi → Proses → Selesai) → 6. Sistem mencatat perubahan status di log → 7. Sistem mengirim notifikasi status → 8. Sistem menjadwalkan notifikasi STNK (7 hari) dan BPKB (30-60 hari) setelah status selesai → 9. Customer menerima notifikasi pengingat pengambilan.
Skenario Alternatif A1: Admin batalkan transaksi → sistem update status dibatalkan dan notif customer
A2: Notifikasi otomatis gagal → admin dapat alert di dashboard dan mengirim notifikasi secara manual dari halaman detail transaksi.

sequenceDiagram
    autonumber
    actor Customer as Customer
    participant HlmNotif as HlmNotifCustomer
    actor Admin as Admin
    participant FormDaftar as Halaman DaftarTransaksi
    participant FormDetail as Halaman DetailTransaksi
    participant Ctrl as Transaksi Controller
    participant DB as Transaksi DataBase

    %% Alur Awal
    Admin->>FormDaftar: bukaDashboardMenu()
    activate Admin
    activate FormDaftar
    FormDaftar->>Ctrl: getDaftarTransaksi()
    activate Ctrl
    Ctrl->>DB: getAll()
    activate DB
    DB-->>Ctrl: return: listTransaksi
    deactivate DB
    Ctrl-->>FormDaftar: return: tampilDaftarTransaksi(data)
    deactivate Ctrl
    FormDaftar-->>Admin: render: DaftarTransaksi
    deactivate FormDaftar
    deactivate Admin

    Admin->>FormDaftar: TextpilihTransaksi(id)
    activate Admin
    activate FormDaftar
    FormDaftar->>Ctrl: requestDetailTransaksi(id)
    activate Ctrl
    Ctrl->>Ctrl: validasiIdTransaksi(id)
    Ctrl->>DB: getById(id)
    activate DB
    DB-->>Ctrl: return: dataTransaksi
    deactivate DB
    Ctrl-->>FormDetail: tampilkanDetailTransaksi()
    activate FormDetail
    deactivate Ctrl
    deactivate FormDaftar
    deactivate Admin

    %% Alt Validasi
    alt [Tidak Valid]
        Ctrl-->>FormDetail: tampilFormAlasan()
        activate FormDetail
        FormDetail-->>Admin: render: FormAlasan
        deactivate FormDetail
        Admin->>FormDetail: isiAlasan(alasan)
        activate Admin
        activate FormDetail
        FormDetail->>Ctrl: submitAlasan(alasan)
        activate Ctrl
        Ctrl->>DB: updateStatus ("Dibatalkan",alasan)
        activate DB
        DB-->>Ctrl: return: statusUpdated
        deactivate DB
        Ctrl->>HlmNotif: kirimNotifikasiPembatalan(idCustomer)
        activate HlmNotif
        HlmNotif->>Customer: bukaNotifikasi()
        activate Customer
        Customer-->>HlmNotif: return: notifikasiDiterima
        deactivate Customer
        HlmNotif-->>Ctrl: return: notifikasiDiterima
        deactivate HlmNotif
        Ctrl-->>FormDetail: return: statusUpdated
        deactivate Ctrl
        FormDetail-->>Admin: render: DetailTransaksi
        deactivate FormDetail
        deactivate Admin
    else [ Valid]
        Ctrl-->>FormDetail: tampilDetail Pembatasan(data)
        activate FormDetail
        FormDetail-->>Admin: render: DetailTransaksi
        deactivate FormDetail
        Ctrl-->>FormDetail: tampilFormPerbaruiStatus()
        activate FormDetail
        FormDetail-->>Admin: render: FormPerbaruiStatus
        deactivate FormDetail
        Admin->>FormDetail: konfirmasiProsesTransaksi(data)
        activate Admin
        activate FormDetail
        FormDetail->>Ctrl: submitProsesTransaksi(data)
        activate Ctrl
        Ctrl->>Ctrl: validasiDataTransaksi(data)
        Ctrl->>DB: setLogStatus(data)
        activate DB
        DB-->>Ctrl: return: logTercatat
        deactivate DB
        Ctrl->>HlmNotif: kirimNotifikasiStatus(idCustomer)
        activate HlmNotif
        HlmNotif->>Customer: bukaNotifikasiStatus()
        activate Customer
        Customer-->>HlmNotif: return: statusDibuka
        deactivate Customer
        HlmNotif-->>Ctrl: return: statusDibuka
        deactivate HlmNotif
        Ctrl-->>FormDetail: tampilDetailStatusTransaksi(data)
        activate FormDetail
        FormDetail-->>Admin: render: DetailStatusTransaksi
        deactivate Ctrl
        deactivate FormDetail
        deactivate Admin

        %% Loop Belum Selesai
        loop [Belum Selesai]
            Admin->>FormDetail: konfirmasiProsesTransaksi(data)
            activate Admin
            activate FormDetail
            FormDetail->>Ctrl: submitProses Transaksi(data)
            activate Ctrl
            Ctrl->>DB: updateStatus Transaksi(id,status)
            activate DB
            DB-->>Ctrl: return: statusDiperbarui
            deactivate DB
            Ctrl-->>FormDetail: return: statusDiperbarui
            deactivate Ctrl
            FormDetail-->>Admin: render: DetailStatusTransaksi
            deactivate FormDetail
            deactivate Admin
        end

        %% Notifikasi STNK/BPKB Flow
        Ctrl->>DB: getNotifSTNKBPKB(id)
        activate Ctrl
        activate DB
        DB-->>Ctrl: return: dataNotif
        deactivate DB
        Ctrl->>Ctrl: validasiNotifDokumen(data)
        Ctrl-->>FormDetail: return: hasilPemeriksaan
        activate FormDetail
        deactivate Ctrl
        deactivate FormDetail

        alt [Notif Gagal]
            Ctrl-->>FormDetail: tampilAlert Dashboard(pesan)
            activate FormDetail
            FormDetail-->>Admin: render: AlertDashboard
            deactivate FormDetail
            Admin->>FormDetail: kirimNotifikasi Manual(pesan)
            activate Admin
            activate FormDetail
            FormDetail->>Ctrl: submitNotifikasi Manual(pesan)
            activate Ctrl
            Ctrl->>HlmNotif: setNotifikasiManual(idCustomer,pesan)
            activate HlmNotif
            HlmNotif->>Customer: bukaNotifikasi()
            activate Customer
            Customer-->>HlmNotif: return: notifikasiDiterima
            deactivate Customer
            HlmNotif-->>Ctrl: return: notifikasiDiterima
            deactivate HlmNotif
            Ctrl-->>FormDetail: return: notifikasiDiterima
            deactivate Ctrl
            deactivate FormDetail
            deactivate Admin
        else [Notif Berhasil]
            Ctrl->>DB: setPengingatPengambilan(id)
            activate Ctrl
            activate DB
            DB-->>Ctrl: return: pengingatDiset
            deactivate DB
            Ctrl->>HlmNotif: setPengingatPengambilan(id)
            activate HlmNotif
            HlmNotif->>Customer: bukaPengingat()
            activate Customer
            Customer-->>HlmNotif: return: pengingatDiterima
            deactivate Customer
            HlmNotif-->>Ctrl: return: pengingatDiterima
            deactivate HlmNotif
            Ctrl-->>FormDetail: tampilInfo Pengambilan(data)
            activate FormDetail
            FormDetail-->>Admin: render: InfoPengambilanDokumen
            deactivate FormDetail
            deactivate Ctrl
        end

        Admin->>FormDetail: prosesSelesai()
        activate Admin
        activate FormDetail
        FormDetail->>Ctrl: prosesSelesai()
        activate Ctrl
        Ctrl->>DB: updateStatus(id, "Selesai")
        activate DB
        DB-->>Ctrl: return: success
        deactivate DB
        Ctrl-->>FormDetail: return: success
        deactivate Ctrl
        FormDetail-->>Admin: render: InfoPengambilanDokumen
        deactivate FormDetail
        deactivate Admin
    end
