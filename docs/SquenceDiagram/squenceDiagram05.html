Pengajuan Kredit Motor

USE CASE SKENARIO — Pengajuan Kredit

Kredit ditolak → sistem update status ditolak & kirim notif penolakan
A4: Pembayaran DP gagal → 
sequenceDiagram
    autonumber
    actor Customer as Customer
    participant FormKatalog as Halaman Katalog
    participant FormKredit as Halaman Customer
    participant Ctrl as Kredit Controller
    participant DB as Penjualan Repo
    participant Notif as Notif Service
    actor Admin as Admin
    participant FormAdmin as Halaman Admin

    %% 1. Pilih Motor & Form
    Customer->>FormKatalog: pilihMotor(motorId, dp, tenor)
    activate Customer
    activate FormKatalog
    FormKatalog->>Ctrl: getFormKredit(motorId)
    activate Ctrl
    Ctrl->>DB: getMotor(id)
    activate DB
    DB-->>Ctrl: return detail
    deactivate DB
    Ctrl->>FormKredit: tampilkanFormKredit()
    activate FormKredit
    deactivate Ctrl
    deactivate FormKatalog
    deactivate FormKredit

    %% Pengisian Data & Validasi Berkas
    Customer->>FormKredit: submitPengajuan(data, dokumen[])
    activate FormKredit
    FormKredit->>Ctrl: validasiForm(data)
    activate Ctrl
    Ctrl->>Ctrl: uploadDokumen(dokumen)
    alt Data Tidak Lengkap
        Ctrl->>Notif: kirimNotifUnggahUlang(id)
        activate Notif
        Notif->>FormKredit: tampilkanNotifUnggahUlang()
        deactivate Notif
        Ctrl-->>FormKredit: return error
    else Data Lengkap & Valid
        Ctrl->>DB: save(data)
        activate DB
        DB-->>Ctrl: return success
        deactivate DB
        Ctrl-->>FormKredit: return success
        FormKredit->>FormKredit: tampilkanStatus("Terkirim")
    end
    deactivate Ctrl
    deactivate FormKredit
    deactivate Customer

    %% 3. Admin & Leasing
    Admin->>FormAdmin: inputJadwalSurvey(id, tanggal)
    activate Admin
    activate FormAdmin
    FormAdmin->>Ctrl: setJadwalSurvey(id, tanggal)
    activate Ctrl
    Ctrl->>DB: update(id, "Dijadwalkan Survey")
    activate DB
    DB-->>Ctrl: return success
    deactivate DB
    Ctrl->>Notif: kirimNotifJadwal(tanggal)
    activate Notif
    Notif->>FormKredit: tampilkanJadwal(tanggal)
    deactivate Notif
    Ctrl-->>FormAdmin: return success
    deactivate Ctrl
    FormAdmin->>FormAdmin: tampilkanStatus("berhasil...")
    deactivate FormAdmin
    deactivate Admin

    %% 4. Keputusan
    Admin->>FormAdmin: inputKeputusanLeasing(id, keputusan)
    activate Admin
    activate FormAdmin
    FormAdmin->>Ctrl: updateKeputusan(id, keputusan)
    activate Ctrl
    Ctrl->>DB: update(id, keputusan)
    activate DB
    DB-->>Ctrl: return success
    deactivate DB
    alt Kredit Ditolak
        Ctrl->>Notif: kirimNotifPenolakan()
        activate Notif
        Notif->>FormKredit: tampilkanHasilKredit("Ditolak")
        deactivate Notif
    else Kredit Disetujui
        Ctrl->>Notif: kirimNotifPersetujuan()
        activate Notif
        Notif->>FormKredit: tampilkanHasilKredit("Disetujui")
        deactivate Notif
    end
    Ctrl-->>FormAdmin: return success
    deactivate Ctrl
    FormAdmin->>FormAdmin: tampilkanStatus("Keputusan Disimpan")
    deactivate FormAdmin
    deactivate Admin

    %% 5. Pembayaran DP
    opt Jika Kredit Disetujui
        Customer->>FormKredit: bayarDP()
        activate Customer
        activate FormKredit
        FormKredit->>Ctrl: prosesPembayaran(dataBayar)
        activate Ctrl
        Ctrl->>Ctrl: validasiPembayaran()
        alt Pembayaran Gagal
            Ctrl-->>FormKredit: return failed
            FormKredit->>FormKredit: tampilkanPesan("Pembayaran gagal")
        else Pembayaran Sukses
            Ctrl->>DB: update(id, "DP Paid")
            activate DB
            DB-->>Ctrl: return success
            deactivate DB
            Ctrl->>Notif: kirimInvoice()
            activate Notif
            Notif->>FormKredit: tampilkanInvoice()
            deactivate Notif
            Ctrl-->>FormKredit: return success
        end
        deactivate Ctrl
        deactivate FormKredit
        deactivate Customer
    end

    %% 6. Selesai & Ambil STNK/BPKB
    Admin->>FormAdmin: updateStatusSelesai(id)
    activate Admin
    activate FormAdmin
    FormAdmin->>Ctrl: selesaikanPenjualan(id)
    activate Ctrl
    Ctrl->>DB: update(id, "selesai")
    activate DB
    DB-->>Ctrl: return success
    deactivate DB
    Ctrl->>Notif: kirimNotifStnk()
    activate Notif
    Notif->>FormKredit: tampilkanInstruksiPengambilan()
    deactivate Notif
    Ctrl-->>FormAdmin: return success
    deactivate Ctrl
    FormAdmin->>FormAdmin: tampilkanStatus("selesai")
    deactivate FormAdmin
    deactivate Admin

    Customer->>FormKredit: ambilStnkBpkb()
    activate Customer
    activate FormKredit
    FormKredit->>FormKredit: tampilkanPetunjukPengambilan()
    deactivate FormKredit
    deactivate Customer
Use Case ID UC-05
Nama Use Case Mengajukan Kredit Motor
Aktor Customer, Admin, Sistem
Deskripsi Customer memilih motor, menentukan DP & tenor, mengisi data pribadi dan pekerjaan, mengunggah dokumen, lalu mengirim pengajuan. Admin memverifikasi, menjadwalkan survei, dan memberi keputusan. Jika disetujui, customer melakukan pembayaran DP digital dan menerima STNK/BPKB.
Precondition Customer sudah login, motor tersedia di katalog
Postcondition Status kredit selesai, STNK/BPKB dijadwalkan
Skenario Utama 1. Customer pilih motor, DP & tenor → 2. Sistem tampil form → 3. Isi data + upload dokumen → 4. Kirim pengajuan → 5. Sistem validasi kelengkapan → 6. Simpan & notif Admin → 7. Admin periksa & teruskan ke leasing → 8. Jadwalkan survei → 9. Admin input hasil keputusan → 10. Sistem update status & notif customer → 11. Customer bayar DP digital → 12. Sistem kirim invoice & jadwal STNK/BPKB
