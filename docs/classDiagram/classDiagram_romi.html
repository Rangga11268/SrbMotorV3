Class Diagram — Opsi C (Fokus Relasi Arsitektur)

Sesuai dengan referensi materi, isi metode pada Boundary dan Entity disembunyikan (suppressed) agar diagram terlihat bersih, tidak memakan tempat, dan terfokus pada topologi garis/relasi antar kelas BCE.

    %% ==========================================
    %% COLUMN 1: KATALOG & PEMESANAN (Motor)

    class HalamanUtama
    class HalamanKatalog

        +getSemuaMotor() void
        +validasiInput(query, filter) void

    }
    class PemesananController {
        +cekStok(idMotor) void
        +redirectPembayaran() void
    }
    class KategoriMotor
    class Motor

    <<boundary>> HalamanUtama
    <<boundary>> HalamanKatalog
    <<boundary>> FormPemesanan
    <<control>> KatalogController
    <<control>> PemesananController
    <<entity>> KategoriMotor
    <<entity>> Motor

    HalamanKatalog --> KatalogController : dikelola oleh
    FormPemesanan --> PemesananController : dikelola oleh
    KatalogController --> Motor : mengakses
    PemesananController --> Motor : mengakses
    KategoriMotor o-- Motor : memiliki
