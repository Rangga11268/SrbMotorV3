USE CASE SKENARIO — Booking Servis

Use Case ID UC-06
Nama Use Case Melakukan Booking Servis
Aktor Customer, Admin, Montir, Sistem
Deskripsi Customer memilih jadwal & cabang servis, mengisi keluhan, dan mengirim booking. Sistem cek ketersediaan montir. Montir mengerjakan servis, input rincian biaya, dan Admin/Sistem memproses pembayaran via Midtrans atau cash, lalu kirim invoice digital.
Precondition Customer sudah login, ada montir aktif di cabang yang dipilih
Postcondition Status servis paid, invoice terkirim ke Customer
Skenario Utama 1. Customer pilih jadwal & cabang → 2. Isi keluhan → 3. Kirim booking → 4. Sistem cek ketersediaan montir → 5. Generate tiket & notif → 6. Montir buka manajemen servis → 7. Ubah status "Sedang Dikerjakan" → 8. Ubah status "Selesai" → 9. Input rincian biaya → 10. Simpan tagihan → 11. Sistem notif customer bayar → 12. Customer klik bayar → 13. Pilih metode bayar → 14. Sistem proses pembayaran → 15. Kirim invoice digital
Skenario Alternatif A1: Jadwal penuh → sistem kirim pesan jadwal penuh
A2: Customer batalkan saat sedang dikerjakan → sistem kirim pesan tidak bisa batal
A3: Total biaya = 0 → sistem kirim pesan tagihan tidak boleh 0
A4: Pembayaran gagal → sistem kirim pesan bayar gagal
sd Booking Servis Motor
sequenceDiagram
    autonumber
    actor Customer as Customer
    participant FormServis as Halaman_Customer
    participant FormPembayaran as Halaman_Pembayaran
    actor Admin as Admin
    participant FormAdmin as Halaman_Admin
    actor Montir as Montir
    participant FormMontir as Halaman_Montir
    participant Ctrl as ServisController
    participant DB as ServisRepo

    %% 1. Booking Servis
    Customer->>FormServis: inputBooking(idCustomer, tanggal, cabang, keluhan)
    activate Customer
    activate FormServis
    FormServis->>Ctrl: validasiBooking(idCustomer, tanggal, cabang, keluhan)
    activate Ctrl
    Ctrl->>DB: getKetersediaan(tanggal, cabang)
    activate DB
    DB-->>Ctrl: return ketersediaan
    deactivate DB
    alt Slot Penuh
        Ctrl-->>FormServis: return penuh
        FormServis->>FormServis: tampilkanPesanJadwalPenuh()
    else Slot Tersedia
        Ctrl->>DB: set(booking)
        activate DB
        DB-->>Ctrl: return bookingId
        deactivate DB
        Ctrl-->>FormServis: return success
        FormServis->>FormServis: tampilkanTiketDigital()
    end
    deactivate Ctrl
    deactivate FormServis
    deactivate Customer

    %% 2. Konfirmasi Admin
    Admin->>FormAdmin: konfirmasiJadwal(bookingId, idMontir)
    activate Admin
    activate FormAdmin
    FormAdmin->>Ctrl: konfirmasiBooking(bookingId, idMontir)
    activate Ctrl
    Ctrl->>DB: update(bookingId, idMontir, "Confirmed")
    activate DB
    DB-->>Ctrl: return success
    deactivate DB
    Ctrl-->>FormServis: kirimNotifikasiJadwal()
    activate FormServis
    FormServis->>FormServis: tampilkanNotifKonfirmasi()
    deactivate FormServis
    Ctrl-->>FormAdmin: return success
    deactivate Ctrl
    FormAdmin->>FormAdmin: tampilkanJadwalTerkonfirmasi()
    deactivate FormAdmin
    deactivate Admin

    %% 3. Customer Batalkan (Optional)
    opt Batalkan Servis
        Customer->>FormServis: batalkanServis(bookingId)
        activate Customer
        activate FormServis
        FormServis->>Ctrl: batalkanBooking(bookingId)
        activate Ctrl
        Ctrl->>DB: cancelBooking(bookingId)
        activate DB
        DB-->>Ctrl: return status
        deactivate DB
        alt Sedang Kerja
            Ctrl-->>FormServis: return tidakBisaBatal
            FormServis->>FormServis: tampilkanPesan("Tidak Bisa Batal")
        else Belum Dikerjakan
            Ctrl-->>FormServis: return batalSukses
            FormServis->>FormServis: tampilkanPesan("Batal Sukses")
        end
        deactivate Ctrl
        deactivate FormServis
        deactivate Customer
    end

    %% 4. Pekerjaan Montir & Tagihan
    Montir->>FormMontir: lihatDaftarKerjaan()
    activate Montir
    activate FormMontir
    FormMontir->>Ctrl: getKerjaan()
    activate Ctrl
    Ctrl->>DB: fetchByMontir()
    activate DB
    DB-->>Ctrl: return daftarKerjaan
    deactivate DB
    Ctrl-->>FormMontir: return daftarKerjaan
    deactivate Ctrl
    FormMontir->>FormMontir: tampilkanDaftarKerjaan()
    deactivate FormMontir
    deactivate Montir

    Montir->>FormMontir: updateKerjaan(id, "Dikerjakan")
    activate Montir
    activate FormMontir
    FormMontir->>Ctrl: updateStatus(id, "Dikerjakan")
    activate Ctrl
    Ctrl->>DB: update(id, "Dikerjakan")
    activate DB
    DB-->>Ctrl: return success
    deactivate DB
    Ctrl-->>FormServis: kirimNotifMulaiServis()
    activate FormServis
    FormServis->>FormServis: tampilkanNotifMulaiServis()
    deactivate FormServis
    Ctrl-->>FormMontir: return success
    deactivate Ctrl
    FormMontir->>FormMontir: menampilkanStatus("Sedang Dikerjakan")
    deactivate FormMontir
    deactivate Montir

    Montir->>FormMontir: selesaikanDanTagih(id, rincianBiaya)
    activate Montir
    activate FormMontir
    FormMontir->>Ctrl: validasiTagihan(id, rincianBiaya)
    activate Ctrl
    alt Total == 0
        Ctrl-->>FormMontir: return tagihanNol
        FormMontir->>FormMontir: tampilkanPesan("Tagihan tidak boleh 0")
    else Total > 0
        Ctrl->>DB: update(id, "Selesai & Unpaid", rincianBiaya)
        activate DB
        DB-->>Ctrl: return success
        deactivate DB
        Ctrl-->>FormPembayaran: kirimNotifTagihan()
        activate FormPembayaran
        FormPembayaran->>FormPembayaran: tampilkanTagihan()
        deactivate FormPembayaran
        Ctrl-->>FormMontir: return success
        FormMontir->>FormMontir: tampilkanBiayaTersimpan()
    end
    deactivate Ctrl
    deactivate FormMontir
    deactivate Montir

    %% 5. Customer Bayar
    Customer->>FormPembayaran: klikBayar(id)
    activate Customer
    activate FormPembayaran
    FormPembayaran->>Ctrl: getOpsiBayar(id)
    activate Ctrl
    Ctrl-->>FormPembayaran: return opsiBayar
    deactivate Ctrl
    FormPembayaran->>FormPembayaran: tampilkanOpsiBayar()
    deactivate FormPembayaran
    deactivate Customer

    alt Bayar via Midtrans
        Customer->>FormPembayaran: bayarDigital()
        activate Customer
        activate FormPembayaran
        FormPembayaran->>Ctrl: bayarMidtrans(id)
        activate Ctrl
        Ctrl->>DB: update(id, "Paid")
        activate DB
        DB-->>Ctrl: return status
        deactivate DB
        alt Pembayaran Sukses (Lunas)
            Ctrl-->>FormPembayaran: return success
            FormPembayaran->>FormPembayaran: tampilkanInvoice()
        else Pembayaran Gagal
            Ctrl-->>FormPembayaran: return gagal
            FormPembayaran->>FormPembayaran: tampilkanPesan("Bayar Gagal")
        end
        deactivate Ctrl
        deactivate FormPembayaran
        deactivate Customer
    else Bayar di Bengkel (Cash)
        Admin->>FormAdmin: konfirmasiBayarCash(id)
        activate Admin
        activate FormAdmin
        FormAdmin->>Ctrl: prosesPembayaranCash(id)
        activate Ctrl
        Ctrl->>DB: update(id, "Paid")
        activate DB
        DB-->>Ctrl: return success
        deactivate DB
        Ctrl-->>FormPembayaran: kirimInvoiceDigital()
        activate FormPembayaran
        FormPembayaran->>FormPembayaran: tampilkanInvoice()
        deactivate FormPembayaran
        Ctrl-->>FormAdmin: return success
        deactivate Ctrl
        FormAdmin->>FormAdmin: tampilkanPembayaranLunas()
        deactivate FormAdmin
        deactivate Admin
    end
